Rhythm Dodge - Space dodge art pack v1

Art direction: one compact player ship dodging incoming asteroids and a planetary close-pass hazard. The planet is an environmental obstacle, not an enemy to tap/attack.

The PNGs were generated with a baked checkerboard removed and cropped to true transparent alpha. Existing background can remain unchanged. Put gameplay assets in assets/generated/ and ship poses in assets/generated/player/ if preferred; the Codex prompt maps the names.

Paired top/bottom shield markers, circular timing rings, connector, note trails, long-note tail cue and energy progress should be drawn as vector/canvas elements for exact alignment.
